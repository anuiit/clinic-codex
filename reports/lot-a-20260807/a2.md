## Caveats

- **Pretraitement** : Les predictions «deployees» sont calculees a partir des features mises en cache par le pipeline de recherche (base_features des caches OOF v9, backbone dinov2_vits14, image_size 224, S/14, white-pad — parite verifiee en Phase 0 face a la config du runtime deploye), et non par une relecture directe des images brutes a travers le runtime deploye. L'equivalence deploye repose donc sur cette parite de pipeline plus la preuve du gate de calibration C1 (Phase 0, check 3 : 50/50 correspondances exactes top-1, 50/50 top-3 sur le pilote 50-lignes). Important : ce gate de calibration valide que le checkpoint de RECHERCHE C1 reproduit les c1_topk stockes — il ne valide PAS que les PROTOTYPES DEPLOYES (prototypes.pt) sont bien calibres sur ces memes features en cache. La precision deployee mesuree ici sur les 653 lignes OOF est faible (voir la section 'Verification de sanite'), et une verification independante sur le split TRAIN (bien plus grand, mêmes fichiers de cache) montre une precision egalement faible (quelques %), ce qui suggere un ecart plus large que le seul bruit de petit echantillon (U2 du registre d'incertitudes) plutot qu'une anomalie isolee au sous-ensemble OOF.

- **U1 (provenance)** : Incertitude U1 (registre du plan) : le runtime deploye a potentiellement vu des sources apparentees a certaines des 653 lignes (prefixe row_id «external:» = corpus externe, provenance disjointe d'apres l'audit de provenance v8 ; prefixe «legacy:» = lignes historiques potentiellement provenance-adjacentes a l'entrainement deploye). ## Gate MDE — PRE-ANNONCE (avant les tirages bootstrap)

Les chiffres de cette section sont calcules analytiquement (ANOVA / ICC) AVANT le bootstrap ci-dessous, conformement au pre-enregistrement (B5).

| bras | ICC (diagnostique) | SE analytique (cluster) | demi-largeur 95% analytique | MDE 80% analytique |
|---|---|---|---|---|
| b0 | 0.2824 | 0.0236 | 0.0462 | 0.0660 |
| c1 | 0.3364 | 0.0267 | 0.0523 | 0.0748 |
| r2 | 0.4038 | 0.0288 | 0.0564 | 0.0806 |

Methodologie (c1) : ICC(1) diagnostique via ANOVA a un facteur non equilibre : ICC = (MSB-MSW)/(MSB+(n0-1)*MSW), n0 = correction de Kish pour tailles inegales = (N - sum(n_k^2)/N)/(K-1). SE analytique du gate MDE : estimateur de variance lineaire pour un ratio en echantillonnage par grappes AVEC REMISE (Woodruff 1971, equivalent au jackknife delete-a-group) — adapte au schema de rechantillonnage reellement utilise plus bas (K composantes tirees avec remise parmi les K disponibles, toutes les lignes d'une composante tiree ensemble) : z_k = sum_delta(k) - n_k*moyenne_globale (residu pondere par taille, somme nulle par construction) ; Var_hat = sum(z_k^2) / (K*(K-1)*taille_moyenne^2) ; demi-largeur 95% analytique = z_0.975*SE (z_0.975=1.959964) ; MDE_80% analytique = (z_0.975+z_0.80)*SE (z_0.80=0.841621), approximation normale bilaterale alpha=0.05 / puissance=80%.
