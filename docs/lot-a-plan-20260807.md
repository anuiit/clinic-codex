## Phase A1 — Intersection des flips (aucune dépendance caches)
Sur les 1 959 lignes : correct(arm) = (topk[0] == label). Flip B0→C1 = correct différent ; idem C1→R2. Classes {both-flip, only-B0C1, only-C1R2, neither} par ligne×seed ; taux de partage = |flips(B0→C1) ∩ flips(C1→R2)| / |union| (Jaccard) + décomposition amélioration/dégradation ; ventilation par fold, seed, composante, classe. Consistance inter-seeds : test des signes exact (n=3 — PAS d'IC), + probabilité postérieure Beta(1,1). Livrable : verdict descriptif « un phénomène vs deux » = si les lignes flippées C1→R2 recouvrent majoritairement celles de B0→C1 (seuil de Jaccard pré-enregistré dans le rapport AVANT calcul : préciser 0.5) — sinon deux phénomènes distincts.
Tests : fixtures synthétiques (all-flip, no-flip, mixte, égalités top-3), planted Jaccard connu.

## Phase A2 — Bootstrap apparié groupé vs runtime déployé
1. Prédictions déployées par ligne : proj(base_features) → L2 → cosinus vs prototypes.pt → top-1 (CPU, 653×384, trivial). Charger via wrapper lecture seule qui vérifie les 3 SHA avant/après.
2. Design apparié par ligne (653 uniques ; seeds moyennés côté bras de recherche uniquement — le déployé est déterministe) : Δ = correct(arm) − correct(deployed) pour arm ∈ {B0, C1, R2}. Primaire : C1 vs déployé ; secondaires : B0, R2 ; Holm sur les 3.
3. Bootstrap par cluster au niveau **provenance_component** (rééchantillonnage des composantes, 10 000 tirages, percentile 95%), stratifié par fold en rapport annexe (pas de pooling silencieux). Pré-annoncer la demi-largeur attendue (~0.05-0.08 avec ~25 composantes) dans le rapport avant le run.
4. Livrable-clé : demi-largeur d'IC observée → recalcul de la cible de composantes pour résoudre 0.01 (extrapolation 1/√k, avec l'ICC empirique) → tranche {~25-30 / ~42 / plus}.
5. Caveat de fond dans le rapport : le déployé a potentiellement vu des sources apparentées à certaines lignes (row_ids `external:*` = corpus externe provenance-disjoint d'après v8 — citer l'évidence, marquer l'hypothèse).
Tests : fixture synthétique clusterisée avec effet et ICC plantés → couverture d'IC nominale (smoke), comptage de composantes exact, alignement d'appariement.
Abort : calibration Phase 0 échouée → A2 non exécuté (rapport de blocage) ; jamais de proxy.
